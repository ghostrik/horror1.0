# ГАЛАКТИКА — тестовая демо-версия хоррора (Unity)

Ночь в закрытом торговом центре. Блогер сам отправил команду домой, чтобы «одному было страшнее»,
закрыл решётку изнутри «для антуража», а она заела по-настоящему. Выход только через гипермаркет,
а в гипермаркете живёт **Мерчандайзер**: сломанный манекен-промоутер, застрявший в петле «обслуживания клиента».

Это **вертикальный срез** будущей игры: зоны 1–2 из 5 (атриум/фудкорт и гипермаркет), ~10–20 минут геймплея.

## Как открыть

1. Установи **Unity 2022.3 LTS** (проект сделан под 2022.3; Unity 6 тоже откроет и предложит обновить — соглашайся).
2. Unity Hub → **Add → Add project from disk** → выбери папку репозитория.
3. Дождись первого импорта (генерируется папка `Library`, пара минут).
4. Открой `Assets/Scenes/MainMenu.unity` → **Play**.
   Сразу в игру: `Assets/Scenes/Mall.unity`.

Рендер: **Built-in Render Pipeline**, цветовое пространство Linear, сторонние пакеты не нужны.

## Что внутри

**Карта — настоящая Unity-сцена**, а не генерация скриптом в рантайме. Каждая стена, стеллаж, лампа и манекен —
обычный GameObject в `Mall.unity`: двигай, удаляй, добавляй в редакторе. Корни иерархии:
`--- LEVEL ---` (Geometry / Props / Lighting / Decals / Audio) и `--- GAMEPLAY ---` (игрок, монстр, двери, предметы, триггеры).

**Сюжетный поток демо**
1. Интро-титры → атриум у заевшей решётки. Туториал: свет, бег, присед, укрытия (фотобудка).
2. Цель: другой выход. Предохранитель №1 в пиццерии → у входа в «Корзину» мелькает тень, громкая связь сходит с ума.
3. Предохранитель №2 в гипермаркете → Мерчандайзер просыпается, начинается охота.
4. Предохранитель №3 в комнате персонала → щитовая → рубильник (громко!) → рольставня в техкоридор → конец демо.
5. Лор (необязательный): чек из кофейни, служебная записка, детский рисунок, VHS-кассета, журнал электрика.

**Мерчандайзер (ИИ)** — `Assets/Scripts/AI`
- Состояния: сон → патруль → проверка шума → погоня → поиск.
- Слышит шаги (бег громче, присед почти беззвучен), двери, щиток. Видит конусом, дальше, если у тебя горит фонарик.
- Сам открывает двери, в погоне — с ноги.
- Рваное движение аниматроники: замирает и рывком «догоняет» позицию, как при лаге.
- Глаза — LED-табло с бегущей строкой «ДОБРО ПОЖАЛОВАТЬ» / «ПОКУПАТЕЛЬ ОБНАРУЖЕН».
- Искажённый рекламный джингл ускоряется, когда он рядом.
- Не видит тебя в укрытии, **если не заметил, как ты туда залез**.
- Путь ищет по сетке `NavGrid`, которая запекается при старте по коллайдерам сцены:
  перестроишь уровень — монстр подстроится сам, NavMesh запекать не нужно.

**Атмосфера**: пост-эффект «камеры телефона» (зерно, аберрация, виньетка, срывы строк, красная вспышка),
мерцающие лампы (сходят с ума рядом с монстром), гирлянды на таймере, лунный свет из фонаря в потолке,
уличный свет сквозь решётку, пыль в луче, громкая связь с объявлениями, «режиссёр страха»
(шёпот за спиной, далёкие звуки, хлопки дверей), сердцебиение и дыхание от страха, скример.

```

  Scenes/      MainMenu.unity, Mall.unity
  Scripts/
    Core/      GameManager (сюжет, HUD, меню паузы), MainMenu, HInput, NoiseSystem
    Player/    PlayerController, Flashlight (телефон), Interactor
    AI/        MonsterAI, MonsterAnimator, NavGrid
    World/     Door, HidingSpot, FusePickup, FuseBox, RollingShutter, NotePickup,
               BatteryPickup, Inspectable, ScareTrigger, Apparition, ExitTrigger,
               PASystem, AmbientDirector
    FX/        HorrorPostFX, FlickerLight, GarlandTimer, SwingingLamp, TVStatic,
               DustMotes, AmbientEmitter
  Shaders/     WorldTriplanar (текстуры по мировым координатам), UnlitGlow, Decal, Dust, HorrorPostFX
  Materials/   97 материалов
  Textures/    процедурные текстуры (плитка ТЦ, стены, товары, вывески, лицо манекена, LED-табло...)
  Audio/       синтезированные звуки (джингл, объявления, шаги, скример, эмбиент...)
```

## Как расширять

- **Новая зона**: собирай геометрию из кубов с материалами `M_Wall*` / `M_Floor*` — шейдер `WorldTriplanar`
  кладёт текстуру по мировым координатам, UV-развёртка не нужна. Расширь `width/depth` у `NavGrid`.
- **Маршрут монстра**: пустышки в `--- GAMEPLAY --- / PatrolPoints`.
- **Пугалка**: объект с `BoxCollider (Is Trigger)` + `ScareTrigger` (звук, захлопнуть дверь, погасить лампы, призрак, фраза).
- **Лор**: любой объект с коллайдером + `NotePickup` (заголовок и текст в инспекторе).
- **Укрытие**: `HidingSpot` + точки `HidePoint` / `ExitPoint`.
- **Тексты** интро, объявлений громкой связи и записок редактируются прямо в инспекторе.

## Честно о статусе

Весь код компилируется против сборок UnityEngine (проверено компилятором). Сцены проверены валидатором:
все ссылки, GUID и поля скриптов сходятся. Запустить сам редактор Unity в среде сборки было нельзя,
поэтому свет, баланс скорости монстра и громкость звуков настраивались на глаз — подкрути в инспекторе под себя.
